# Cost Data Hooks Documentation\n\nComprehensive React hooks for fetching, managing, and monitoring cost data from the RAPID MCP server.\n\n## Overview\n\nThe cost data hooks provide a unified interface for accessing cost metrics, budget information, and financial data across agents and sessions. All hooks include:\n\n- **Automatic Polling**: Configurable intervals with smart caching\n- **Error Handling**: Graceful error states and recovery\n- **Loading States**: Track fetch progress\n- **Manual Refetch**: Force immediate updates when needed\n- **Caching**: Prevent redundant API calls with configurable TTL\n\n## Hooks\n\n### `useCostSummary(periodHours?, enabled?, refreshInterval?)`\n\nFetches overall cost breakdown by model and agent for a specified time period.\n\n**Parameters:**\n- `periodHours` (number, default: 24) - Time period to summarize in hours\n- `enabled` (boolean, default: true) - Enable/disable polling\n- `refreshInterval` (number, default: 60000) - Polling interval in milliseconds\n\n**Returns:**\n```typescript\n{\n  data: CostSummaryData | null;\n  loading: boolean;\n  error: string | null;\n  refetch: () => Promise<void>;\n}\n```\n\n**Example:**\n```typescript\nimport { useCostSummary } from '@/hooks/useCostData';\n\nfunction CostOverview() {\n  const { data, loading, error, refetch } = useCostSummary(24);\n\n  if (loading) return <div>Loading cost summary...</div>;\n  if (error) return <div>Error: {error}</div>;\n\n  return (\n    <div>\n      <h2>Cost Summary (Last 24 hours)</h2>\n      <p>Total Cost: ${data?.totalCost.toFixed(2)}</p>\n      <p>Input Tokens: {data?.inputTokens.toLocaleString()}</p>\n      <p>Output Tokens: {data?.outputTokens.toLocaleString()}</p>\n      \n      <h3>By Model</h3>\n      {data?.byModel.map(m => (\n        <div key={m.model}>\n          <strong>{m.model}:</strong> ${m.cost.toFixed(2)} \n          ({m.percentOfTotal.toFixed(1)}%)\n        </div>\n      ))}\n      \n      <h3>By Agent</h3>\n      {data?.byAgent.map(a => (\n        <div key={a.agentId}>\n          <strong>{a.agentName || a.agentId}:</strong> ${a.cost.toFixed(2)}\n          ({a.tasksCompleted} tasks)\n        </div>\n      ))}\n      \n      <button onClick={refetch}>Refresh</button>\n    </div>\n  );\n}\n```\n\n**Type Definition:**\n```typescript\ninterface CostSummaryData {\n  totalCost: number;\n  inputTokens: number;\n  outputTokens: number;\n  cacheReadTokens?: number;\n  cacheWriteTokens?: number;\n  byModel: CostByModel[];\n  byAgent: CostByAgent[];\n  periodHours: number;\n  timestamp: number;\n}\n\ninterface CostByModel {\n  model: string;\n  cost: number;\n  inputTokens: number;\n  outputTokens: number;\n  percentOfTotal: number;\n}\n\ninterface CostByAgent {\n  agentId: string;\n  agentName?: string;\n  cost: number;\n  tasksCompleted: number;\n  costPerTask: number;\n}\n```\n\n---\n\n### `useCostRecords(filter?, enabled?, refreshInterval?)`\n\nFetches detailed cost records with optional filtering by agent, model, date range, and cost threshold.\n\n**Parameters:**\n- `filter` (CostRecordsFilter, default: {}) - Filter options\n- `enabled` (boolean, default: true) - Enable/disable polling\n- `refreshInterval` (number, default: 120000) - Polling interval in milliseconds\n\n**Filter Options:**\n```typescript\ninterface CostRecordsFilter {\n  agentId?: string;           // Filter by agent ID\n  model?: string;             // Filter by model (opus, sonnet, haiku)\n  startDate?: Date;           // Start of date range\n  endDate?: Date;             // End of date range\n  minCost?: number;           // Minimum cost threshold\n  maxCost?: number;           // Maximum cost threshold\n}\n```\n\n**Returns:**\n```typescript\n{\n  data: CostRecord[];\n  loading: boolean;\n  error: string | null;\n  refetch: () => Promise<void>;\n}\n```\n\n**Example:**\n```typescript\nimport { useCostRecords } from '@/hooks/useCostData';\n\nfunction CostRecordsTable({ agentId }) {\n  const { data: records, loading, error } = useCostRecords(\n    {\n      agentId,\n      startDate: new Date(Date.now() - 7 * 24 * 60 * 60 * 1000), // Last 7 days\n      minCost: 0.01, // Only show costs >= $0.01\n    },\n    true,\n    120000 // Refresh every 2 minutes\n  );\n\n  if (loading) return <div>Loading records...</div>;\n  if (error) return <div>Error: {error}</div>;\n\n  return (\n    <table>\n      <thead>\n        <tr>\n          <th>Timestamp</th>\n          <th>Agent</th>\n          <th>Model</th>\n          <th>Tokens (in/out)</th>\n          <th>Cost</th>\n        </tr>\n      </thead>\n      <tbody>\n        {records.map(r => (\n          <tr key={r.id}>\n            <td>{new Date(r.timestamp).toLocaleString()}</td>\n            <td>{r.agentName || r.agentId}</td>\n            <td>{r.model}</td>\n            <td>{r.inputTokens}/{r.outputTokens}</td>\n            <td>${r.cost.toFixed(4)}</td>\n          </tr>\n        ))}\n      </tbody>\n    </table>\n  );\n}\n```\n\n**Type Definition:**\n```typescript\ninterface CostRecord {\n  id: string;\n  timestamp: string;\n  agentId: string;\n  agentName?: string;\n  model: string;\n  inputTokens: number;\n  outputTokens: number;\n  cacheReadTokens?: number;\n  cacheWriteTokens?: number;\n  cost: number;\n  taskId?: string;\n  session?: string;\n}\n```\n\n---\n\n### `useAgentBudget(agentId, enabled?, refreshInterval?)`\n\nMonitors an individual agent's budget and spending.\n\n**Parameters:**\n- `agentId` (string) - The agent ID to monitor\n- `enabled` (boolean, default: true) - Enable/disable polling\n- `refreshInterval` (number, default: 30000) - Polling interval in milliseconds\n\n**Returns:**\n```typescript\n{\n  data: AgentBudgetData | null;\n  loading: boolean;\n  error: string | null;\n  refetch: () => Promise<void>;\n}\n```\n\n**Example:**\n```typescript\nimport { useAgentBudget } from '@/hooks/useCostData';\n\nfunction AgentBudgetCard({ agentId }) {\n  const { data: budget, loading, error } = useAgentBudget(agentId, true, 30000);\n\n  if (loading) return <div>Loading budget...</div>;\n  if (error) return <div>Error: {error}</div>;\n\n  const statusColor = {\n    ok: 'bg-green-100',\n    warning: 'bg-yellow-100',\n    exceeded: 'bg-red-100',\n  }[budget?.status || 'ok'];\n\n  return (\n    <div className={`p-4 rounded ${statusColor}`}>\n      <h3>{budget?.agentName || budget?.agentId}</h3>\n      <p>Spent: ${budget?.spent.toFixed(2)}</p>\n      <p>Limit: ${budget?.limit.toFixed(2)}</p>\n      <div className=\"w-full bg-gray-300 rounded\">\n        <div \n          className=\"bg-blue-500 h-2 rounded\"\n          style={{ width: `${Math.min(budget?.percentUsed ?? 0, 100)}%` }}\n        />\n      </div>\n      <p className=\"text-sm\">{budget?.percentUsed.toFixed(0)}% used</p>\n      \n      {budget?.status === 'exceeded' && (\n        <p className=\"text-red-600 font-bold\">Budget exceeded!</p>\n      )}\n      {budget?.status === 'warning' && (\n        <p className=\"text-orange-600\">Approaching limit</p>\n      )}\n    </div>\n  );\n}\n```\n\n**Type Definition:**\n```typescript\ninterface AgentBudgetData {\n  agentId: string;\n  agentName?: string;\n  spent: number;\n  limit: number;\n  percentUsed: number;\n  remainingBudget: number;\n  projectedOverage?: number;\n  status: 'ok' | 'warning' | 'exceeded';\n}\n```\n\n**Status Levels:**\n- `'ok'`: Used < 90% of budget\n- `'warning'`: Used 90-99% of budget\n- `'exceeded'`: Used >= 100% of budget\n\n---\n\n### `useSessionBudget(sessionId?, enabled?, refreshInterval?)`\n\nMonitors a session's overall budget across all agents.\n\n**Parameters:**\n- `sessionId` (string, optional) - Session ID to monitor (defaults to current session)\n- `enabled` (boolean, default: true) - Enable/disable polling\n- `refreshInterval` (number, default: 60000) - Polling interval in milliseconds\n\n**Returns:**\n```typescript\n{\n  data: SessionBudgetData | null;\n  loading: boolean;\n  error: string | null;\n  refetch: () => Promise<void>;\n}\n```\n\n**Example:**\n```typescript\nimport { useSessionBudget } from '@/hooks/useCostData';\n\nfunction SessionBudgetOverview() {\n  const { data: budget, loading, error } = useSessionBudget();\n\n  if (loading) return <div>Loading budget...</div>;\n  if (error) return <div>Error: {error}</div>;\n\n  return (\n    <div className=\"bg-white p-6 rounded-lg shadow\">\n      <h2>Session Budget</h2>\n      \n      <div className=\"grid grid-cols-3 gap-4\">\n        <div>\n          <p className=\"text-gray-600\">Total Spent</p>\n          <p className=\"text-2xl font-bold\">${budget?.spent.toFixed(2)}</p>\n        </div>\n        \n        <div>\n          <p className=\"text-gray-600\">Limit</p>\n          <p className=\"text-2xl font-bold\">${budget?.limit?.toFixed(2)}</p>\n        </div>\n        \n        <div>\n          <p className=\"text-gray-600\">Remaining</p>\n          <p className=\"text-2xl font-bold text-green-600\">\n            ${budget?.remainingBudget.toFixed(2)}\n          </p>\n        </div>\n      </div>\n      \n      <div className=\"mt-4\">\n        <p className=\"text-sm text-gray-600\">Budget Usage</p>\n        <div className=\"w-full bg-gray-300 rounded h-2\">\n          <div \n            className=\"bg-blue-500 h-2 rounded\"\n            style={{ width: `${Math.min(budget?.percentUsed ?? 0, 100)}%` }}\n          />\n        </div>\n        <p className=\"text-xs text-gray-600 mt-1\">\n          {budget?.percentUsed.toFixed(0)}% used\n        </p>\n      </div>\n      \n      <div className=\"mt-4\">\n        <p className=\"text-sm text-gray-600\">\n          {budget?.agentCount} agents running\n        </p>\n        <p className=\"text-sm text-gray-600\">\n          Average cost per agent: ${budget?.avgCostPerAgent.toFixed(2)}\n        </p>\n      </div>\n    </div>\n  );\n}\n```\n\n**Type Definition:**\n```typescript\ninterface SessionBudgetData {\n  sessionId: string;\n  spent: number;\n  limit?: number;\n  percentUsed: number;\n  remainingBudget: number;\n  agentCount: number;\n  avgCostPerAgent: number;\n}\n```\n\n---\n\n## Helper Functions\n\n### `formatCost(cost: number): string`\n\nFormats a cost value as a currency string with appropriate precision.\n\n```typescript\nformatCost(0.00001)  // \"$0.0000\"\nformatCost(0.1)      // \"$0.100\"\nformatCost(10.5)     // \"$10.50\"\n```\n\n### `formatTokens(tokens: number): string`\n\nFormats token counts with K/M suffixes for readability.\n\n```typescript\nformatTokens(500)      // \"500\"\nformatTokens(1000)     // \"1.0K\"\nformatTokens(1500000)  // \"1.5M\"\n```\n\n### `costPerToken(cost: number, tokens: number): string`\n\nCalculates cost per token with 6 decimal precision.\n\n```typescript\ncostPerToken(0.01, 1000)      // \"0.000010\"\ncostPerToken(1.0, 10000)      // \"0.000100\"\ncostPerToken(0.1, 0)          // \"0\"\n```\n\n---\n\n## Best Practices\n\n### 1. Use Appropriate Refresh Intervals\n\n```typescript\n// Real-time dashboard - update frequently\nconst { data: summary } = useCostSummary(24, true, 10000); // 10 seconds\n\n// Agent details page - less frequent updates\nconst { data: records } = useCostRecords({ agentId }, true, 120000); // 2 minutes\n\n// Budget warnings - check often for threshold crossings\nconst { data: budget } = useAgentBudget(agentId, true, 15000); // 15 seconds\n```\n\n### 2. Disable Polling When Not Visible\n\n```typescript\nfunction CostPanel({ isVisible }) {\n  // Only poll when the panel is visible\n  const { data, refetch } = useCostSummary(24, isVisible);\n\n  return isVisible ? <div>{data?.totalCost}</div> : null;\n}\n```\n\n### 3. Handle Loading and Error States\n\n```typescript\nfunction CostDisplay() {\n  const { data, loading, error, refetch } = useCostSummary();\n\n  if (loading) return <Skeleton />; // Show loading state\n  if (error) return (\n    <div>\n      <p>Failed to load cost data</p>\n      <button onClick={refetch}>Retry</button>\n    </div>\n  );\n\n  return <div>{data?.totalCost}</div>;\n}\n```\n\n### 4. Use Manual Refetch for Critical Updates\n\n```typescript\nfunction BudgetAlert() {\n  const { data: budget, refetch } = useAgentBudget(agentId, true, 30000);\n\n  const handleRefresh = async () => {\n    await refetch();\n    if (budget?.status === 'exceeded') {\n      alert('Budget exceeded! Stopping agents...');\n    }\n  };\n\n  return (\n    <button onClick={handleRefresh}>\n      Check Budget Now\n    </button>\n  );\n}\n```\n\n### 5. Combine Hooks for Complex Dashboards\n\n```typescript\nfunction CostDashboard({ agentId }) {\n  // Fetch multiple data sources\n  const summary = useCostSummary(24);\n  const agentBudget = useAgentBudget(agentId);\n  const sessionBudget = useSessionBudget();\n  const records = useCostRecords({ agentId }, true, 120000);\n\n  // Show loading until all data is ready\n  if (summary.loading || agentBudget.loading || sessionBudget.loading) {\n    return <Skeleton />;\n  }\n\n  // Show combined view\n  return (\n    <div>\n      <CostSummaryCard data={summary.data} />\n      <AgentBudgetCard data={agentBudget.data} />\n      <SessionBudgetCard data={sessionBudget.data} />\n      <CostRecordsTable records={records.data} />\n    </div>\n  );\n}\n```\n\n---\n\n## Performance Considerations\n\n### Caching\n\nAll hooks implement local caching to prevent redundant API calls:\n\n```typescript\nconst summary1 = useCostSummary(24, true, 60000);\n// First call fetches from API and caches result\n\nconst summary2 = useCostSummary(24, true, 60000);\n// Second call with same params returns cached data immediately\n// (if less than 60 seconds have passed since first call)\n```\n\n### Memory Management\n\nPolling intervals are automatically cleaned up when:\n- The component unmounts\n- The `enabled` flag is set to `false`\n- Required parameters (like `agentId`) become `null` or `undefined`\n\n```typescript\nuseEffect(() => {\n  return () => {\n    // Cleanup function automatically clears polling interval\n  };\n}, [enabled, agentId]);\n```\n\n### Polling Manager Integration\n\nFor large dashboards with many hooks, consider using the centralized polling manager from `useMcp`:\n\n```typescript\nimport { useMcp, pollingManager } from '@/hooks/useMcp';\n\nfunction Dashboard() {\n  const { startPolling } = useMcp();\n\n  useEffect(() => {\n    // All data types poll with single interval\n    const unsubscribe = startPolling(5000); // 5 second refresh\n    return unsubscribe; // Cleanup\n  }, [startPolling]);\n\n  return <CostDashboard />;\n}\n```\n\n---\n\n## Error Handling\n\nAll hooks gracefully handle errors and maintain previous data on failure:\n\n```typescript\nconst { data, loading, error, refetch } = useCostSummary();\n\n// If API fails:\n// - data keeps previous value (doesn't become null)\n// - error contains error message\n// - loading is false\n// - refetch() can retry the call\n```\n\n---\n\n## Testing\n\nSee `useCostData.test.ts` for comprehensive test examples:\n\n```typescript\nimport { renderHook, waitFor } from '@testing-library/react';\nimport { useCostSummary } from '@/hooks/useCostData';\n\ntest('fetches cost summary on mount', async () => {\n  const { result } = renderHook(() => useCostSummary(24));\n\n  expect(result.current.loading).toBe(true);\n\n  await waitFor(() => {\n    expect(result.current.loading).toBe(false);\n  });\n\n  expect(result.current.data?.totalCost).toBeGreaterThan(0);\n});\n```\n"
